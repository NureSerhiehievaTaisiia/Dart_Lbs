# lab01 — Каталог фільмів (лабораторна робота 1)

Варіант за номером у списку збірної групи: **17 → варіант 2** (каталог фільмів).

## Що робить програма

Консольний застосунок розбирає CSV-подібні рядки каталогу фільмів, відсіює пошкоджені записи, перевіряє діапазони полів і будує звіти конвеєрами `where` / `map` / `fold`. Класи навмисно не використовуються: дані подано записами (`record`) і функціями.

## Структура

- `bin/lab01.dart` — точка входу, друк результатів.
- `lib/lab01.dart` — фасад бібліотеки.
- `lib/src/` — розбір, валідація, агрегація, константи, зразкові дані.

Такий поділ дозволяє імпортувати логіку з `lib/` у наступних лабораторних роботах і не змішувати вивід із алгоритмами.

## Типи даних

- `FilmRecord` — іменований запис із полями фільму.
- `ParseResult` — пара `(film, error)` замість винятків для очікуваних помилок формату.
- `List`, `Map` — для колекцій і групування за жанром.
- `RegExp` з іменованими групами — перевірка коду `AA-000`.

Альтернатива записам — класи або `Map<String, dynamic>`; відкинуто, бо в ЛР1 класи заборонені, а `dynamic` ускладнює аналіз.

## Залежності з pub.dev

У цій роботі сторонніх runtime-залежностей немає. Використано лише `dev_dependencies: lints` для `package:lints/recommended.yaml`.

Альтернатива `lints` — власний набір правил; відкинуто, бо recommended є вимогою методичних вказівок.
