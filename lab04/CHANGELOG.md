# Changelog

## 1.0.0

- Консольний CLI: `list`, `import`, `fetch`, `serve`.
- Збереження каталогу у JSON і потокове читання CSV через `openRead`.
- HTTP-клієнт до Ghibli API з обробкою трьох рівнів відмов.
- HTTP-сервіс на `shelf` / `shelf_router` з фільтрацією та журналюванням.
- Модульні тести серіалізації, сховища, CLI та обробників.
